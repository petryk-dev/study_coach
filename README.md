# Study Coach

Monorepo for the Study Coach app.

- [`study_coach_backend/`](study_coach_backend) — Node/TypeScript API (Prisma)
- [`study_coach_frontend/`](study_coach_frontend) — Expo / React Native app

Each package has its own `package.json` and `.env.example`; copy `.env.example` to `.env` and run `npm install` inside each folder.
